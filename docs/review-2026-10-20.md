# Scientific and editorial review — October 20, 2026

This pass reviewed active documentation, educational pages, generated planning text, and the search-record and query-checker contracts. It compared scientific claims with the cited sources and software descriptions with the implementation. Historical search logs, records, and the inherited Microsoft tutorial files were retained.

## Corrections and clarification

- Corrected the claim that a broad question is unsuitable for a systematic review. Cochrane permits broad and narrow scopes; the purpose, method, and available resources determine the choice.
- Distinguished review types from analysis methods and modes: meta-analysis is a statistical method, and rapid review describes a streamlined approach. PICO, PCC, SPIDER, and CMO are explained as possible starting structures, not mandatory assignments.
- Corrected the generated reporting guidance: realist synthesis now points to RAMESES, while narrative, integrative, qualitative, and mapping projects receive method-specific guidance rather than an automatic instruction to use PRISMA 2020.
- Clarified that absent outcome reporting is not routinely a reason to exclude an otherwise eligible intervention study. Added the need to account for overlapping primary studies in umbrella reviews.
- Exposed two consequential implementation assumptions: every generated search block is joined by AND, which can make outcome or context requirements too restrictive; and the illustrative flow assumes one retained record per report while combining source pathways. Neither output validates a search or provides a complete review flow.
- Removed the unsupported “most problems” claim and the claim that unprovided Figma/Mermaid submission assets accompany the included SVG. Added source links near educational claims and a complete in-app bibliography.
- Added a [glossary](glossary.md), [assumptions](assumptions.md), and complete [references](references.md). Clarified local-file storage behavior, operator-reported metadata, unknown versus zero counts, immediate predecessor links, and exact-byte fingerprints.
- Corrected active navigation and the translation index: inherited Spanish and Portuguese tutorials describe the Microsoft template, not Review Compass. Original template, policy, license, and translation files remain unchanged; their support contacts are not represented as Review Compass support.

## Source coverage

The [reference audit](reference-audit.json) covers **32 distinct substantive sources**. Fourteen peer-reviewed articles were checked against PubMed metadata and abstracts. One additional rapid-review article had no PubMed abstract; its metadata and the official Cochrane resource pointing to it were checked, but its full findings were not appraised. Seventeen official guidance or software sources were checked at the relevant passages.

Checks distinguished Cochrane chapter-specific update dates, the 2021 PRISMA-S statement from other reporting standards, the version 2 ASReview paper from the current version 3 repository, and W3C's provenance concepts from this project's custom JSON. The source list includes explicit scope and access limits. Targeted DOI and PMID lookups supported this editorial pass; they were not an exhaustive new literature search. The earlier rapid review retains its original search totals and access record.

## Verification

- The complete Node.js suite passed: **29 tests**, covering literal matching, missing inputs, exports, query structure, input limits, operator metadata, and revision records.
- All five active JavaScript modules passed syntax checks. Four direct assertions checked that realist and narrative reporting prompts do not inherit inappropriate generic guidance and that search warnings expose required concept blocks.
- Local Markdown targets and anchors, shared heading order, active HTML asset and fragment links, and the reference-audit schema were checked. Inherited template links were excluded from active-project navigation checks.
- No recorded search results or synthetic search artifacts were regenerated. No deployment was performed.

## Remaining limits

This is a targeted review, not a guarantee that no issue remains. Abstract-only appraisal cannot establish all source methods or results. The project has not been evaluated for retrieval performance, time savings, or research outcomes. It does not execute database searches, make scientific eligibility decisions, authenticate search histories, or validate completed review work. Real projects still require a suitable method, source checks, and human judgment.
