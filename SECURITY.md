# Security

## Reporting a vulnerability

Please report suspected security vulnerabilities privately through this repository's
[GitHub security advisory form](https://github.com/TheThunda01/review-compass/security/advisories/new).
Do not post unresolved vulnerabilities, credentials, or private research records in
public issues.

Include the affected version or commit, the potential impact, and the steps needed
to reproduce the issue. Use synthetic examples where possible and remove secrets
and identifying information from attachments.

For ordinary bugs that do not disclose sensitive information, use the
[issue tracker](https://github.com/TheThunda01/review-compass/issues).

## Project ownership

Review Compass is maintained independently. This reporting process is for
Review Compass, not the Microsoft template from which the repository originated.
The original template's attribution and license remain in
[`TEMPLATE_ORIGIN.md`](TEMPLATE_ORIGIN.md) and [`LICENSE`](LICENSE).
