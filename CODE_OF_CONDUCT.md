# Historical template code of conduct

The original Microsoft portfolio template used the
[Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/).
This page records that upstream context; it does not designate Microsoft as the
moderator or reporting contact for the independently maintained Review Compass
project. See [TEMPLATE_ORIGIN.md](TEMPLATE_ORIGIN.md) for template attribution.

For Review Compass usage questions and bugs, see [SUPPORT.md](SUPPORT.md). For
suspected vulnerabilities, see [SECURITY.md](SECURITY.md). GitHub also provides
[reporting controls for abusive or harmful content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
